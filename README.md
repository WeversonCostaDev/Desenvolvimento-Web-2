# Desenvolvimento-Web-2

Segunda avaliação de desenvolvimento web



Como executar o programa:

no terminal na pasta do projeto digite os seguintes comandos

1. npm install
2. npm run dev



As contas GitHub são todas usadas por mim.



Checklist



Flexbox -> src/css/card.css -.card

CSS Grid -> /src/css/base.css - .container

Media queries -> /src/css/footer.css - @media .lista-rodape ou @media .gif

CSS Variables -> /src/css/base.css - :root , #header.

Image modal -> /src/css/modal.css - Um arquivo inteiro para isso

Animations -> /src/css/header.css - @Keyframes spin

Background -> /src/css/base.css - #header, main, footer

CSS Units -> /src/css/card.css - .card div#autor

Pseudo-elements -> /src/css/header.css - #letreiro-container>div::-webkit-scrollbar

Pseudo-classes ->/src/css/header.css - nav.menu a:hover

Position + z-index -> src/css/modal.css - modal:target img, modal:target a
